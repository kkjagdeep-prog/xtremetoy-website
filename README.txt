PREVIEW ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to preview it in your browser.

DEPLOY WITH VERCEL DROP (QUICK METHOD)
1. Keep index.html, style.css, script.js and any music.mp3 together in one folder.
2. Open https://vercel.com/drop and sign in.
3. Upload the ZIP file or drag the project folder onto the page if prompted.
4. Name the project xtremetoy-profile and deploy.
5. Open the generated website link to test it.
Note: Vercel Drop creates a new project for each upload. For updates to the same URL, use a Git-connected Vercel project instead.

UPDATE AN EXISTING VERCEL PROJECT
If your current Vercel project is connected to GitHub, update these files in the same repository and commit the changes. Vercel will redeploy automatically. If your old project was deployed by direct upload and has no Git repository, you may need to deploy this as a new project or connect a repository.
